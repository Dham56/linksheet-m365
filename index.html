LinkSheet for Microsoft 365

An Excel add-in that turns cells into links to the matching files in OneDrive.

This address hosts the add-in itself, not a download. Excel loads it from here.

Install it into Excel on the web

  1. Save manifest.xml to your computer.
  2. In Excel on the web, open Insert › Office Add-ins › Upload My Add-in.
  3. Choose the file you just saved.

LinkSheet then appears on the Home tab. It reads only the names of the files in the OneDrive folder you choose, never their contents, and it never uploads your workbook.
